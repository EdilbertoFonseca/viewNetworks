**View Networks** — это дополнение для NVDA, которое позволяет **просматривать сохранённые в Windows Wi-Fi сети** и **отображать все сведения о выбранной сети**, включая пароль, **если он сохранён в системе**.

⚠️ **Важно**  
Это дополнение **не взламывает, не подбирает и не пытается получить пароль Wi-Fi**.  
Оно лишь отображает информацию, **уже сохранённую самой Windows**, аналогично команде `netsh wlan show profile`.

---

## Новые возможности текущей версии

- **Единый интерфейс** в одном окне
- Две основные кнопки:
  - **Показать сохранённые сети**
  - **Показать сведения о сети**
- Одно поле вывода с **полным содержимым**, точно так же, как в командной строке
- Ручной выбор **кодировки (encoding)**:
  - `cp850` (по умолчанию)
  - `cp1252`
  - `latin1`
  - `utf-8`
- Автоматическое определение:
  - отсутствия Wi-Fi адаптера
  - компьютеров, подключённых только по кабелю
  - отключённой службы WLAN
- Совместимость с системами **без Wi-Fi**, без ошибок и перезапуска NVDA

## Как использовать

Дополнение можно открыть:

- через **меню Инструменты NVDA**
- либо с помощью **сочетания клавиш**, Windows + Alt + N — открывает главное окно View Networks

### Главное окно

При открытии View Networks пользователю доступны:

1. **Поле выбора кодировки**  
   Позволяет выбрать кодировку, используемую Windows, для корректного отображения текста.

2. **Кнопка «Показать сохранённые сети»** Alt + L  
   Отображает все Wi-Fi сети, сохранённые в системе.

3. **Кнопка «Показать сведения о сети»** Alt + M  
   Запрашивает имя сети и показывает **всю доступную информацию**, включая пароль, если он существует.

4. **Основное текстовое поле**  
   Содержит полный вывод команды `netsh` без фильтрации и изменений.

5. **Кнопка «Закрыть»** Alt + F  
   Закрывает окно.

---

## Поведение на компьютерах без Wi-Fi

Если компьютер:

- не имеет Wi-Fi адаптера, или
- подключён только через Ethernet,

дополнение выведет понятное сообщение о том, что **Wi-Fi интерфейс не обнаружен**, вместе с диагностической информацией, возвращаемой системой.
